About me

I work in digital marketing, and I am learning web analytics.

This website is a practice project. I use it to learn tracking and reporting with real data from my own pages. I follow a 12 week learning plan, and I add each result to this site.

What I practise on this site

  • Write a tracking plan before I build the tags.
  • Set up tags, triggers and variables in Google Tag Manager.
  • Send events and parameters to GA4 with the dataLayer.
  • Test tags with GTM Preview mode and GA4 DebugView.
  • Check data quality, and find the cause when a number looks wrong.
  • Make reports in GA4 and Looker Studio.

What I want to learn next

  • SQL for GA4 data in BigQuery.
  • Adobe Analytics and Piano Analytics.
  • Consent Mode and privacy rules for UK websites.
