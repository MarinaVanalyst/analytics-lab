How a click becomes data

On this site, I can follow each visit from the page to the report.

  1. The page writes to the dataLayerEach page writes its page type. The contact form writes an event called generate_lead.
  2. Google Tag Manager reads itA trigger waits for the event. When it happens, a tag fires and takes the details from variables.
  3. GA4 receives an eventI test it in DebugView, then I use it in reports and explorations.
contact.html
// When someone sends the contact form
dataLayer.push({
  event: 'generate_lead',
  form_id: 'contact-form',
  lead_topic: 'site_feedback'
});

Questions about this site

Why did you build this website?

To practise web analytics with real data. I plan the tracking, build it in Google Tag Manager, test it, and then report on the data.

What data does this site collect?

Google Analytics 4 collects anonymous usage data, for example which pages are viewed, the links and buttons that are clicked, and the type of device. The site does not collect names or email addresses.

Is the contact form real?

It is a practice form. It does not send your message to anyone. It only sends an event called generate_lead, so that I can practise form tracking.

Which tools do you use?

Google Tag Manager, Google Analytics 4, Looker Studio, BigQuery and Excel. The site itself is free hosting on GitHub Pages.
