What I practise here

Tracking

I plan the events, then I set up tags, triggers and variables in Google Tag Manager. They send clicks, scrolls, downloads and form sends to GA4.

Testing and data quality

I test each tag with GTM Preview mode and GA4 DebugView. I check the data on a schedule, and I look for the cause when a number looks wrong.

Reporting

I make reports in GA4 and Looker Studio with the data from this site and from the GA4 demo account. I start each report with the answer to one question.
